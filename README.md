# GreenTech Kampus

Website edukasi interaktif tentang efisiensi energi perangkat digital dan pendingin ruangan berdasarkan SDG 9 dan SDG 13.

## Fitur

# Animasi transisi dan visual interaktif menggunakan Pixi.js, 
# Smooth Scrolling dan kontrol dengan GSAP dan Lenis

- Edukasi tentang energi dan emisi karbon
- Kalkulator jejak energi
- Perbandingan penggunaan aktual dan optimal
- Rekomendasi penghematan energi
- Kuis interaktif


## Teknologi

- HTML
- CSS
- JavaScript
- Vite
- GSAP
- Lenis
- Pixi.js

## Instalasi

Pastikan Node.js sudah terpasang.

```bash
npm install
```

Menjalankan secara lokal

```bash
npm run dev
```

Buka alamat yang ditampilkan, biasanya: http://localhost:5173
