# Leaf texture attribution

The transition uses transparent leaf photographs downloaded from Wikimedia Commons and stored locally so the page does not depend on external image requests at runtime.

- `leaf-kerria.png`: Simon A. Eugster, “BGTransp L Kerria japonica leaf”, CC BY-SA 4.0. Source: https://commons.wikimedia.org/wiki/File:BGTransp_L_Kerria_japonica_leaf.png
- `leaf-pear.png`: Rabe! / User:Fmi2012, “Pear LeafTransparent”, GFDL / CC BY-SA. Source: https://commons.wikimedia.org/wiki/File:Pear_LeafTransparent.png
- `leaf-litchi.png`: B.navez, “Litchi chinensis leaf”, GFDL / CC BY-SA. Source: https://commons.wikimedia.org/wiki/File:Litchi_chinensis_leaf.png
